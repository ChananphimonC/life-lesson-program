# EP12 v2 — สิ่งที่แก้ตามฟีดแบ็ก (2026-11-16)

## ฟีดแบ็กของคุณ → สิ่งที่ทำ
| ฟีดแบ็ก | สิ่งที่แก้ |
|---|---|
| "เอมยิ้มเจ้าเล่ห์" ฟังแปลก | เสียงเล่าไม่บรรยายสีหน้า ท่าทาง เสื้อผ้า หรือว่าใครใส่แว่นดำอีกเลย (ภาพเล่าเอง) |
| ชื่อตัวละครซ้ำ ใช้ตัวเดิม | เปลี่ยนเป็นชุดใหม่ทั้งหมด: **ตังค์**, **บีม**, **พี่นุ่น**, **โค้ชทอง** (ไม่ซ้ำกับต้า ปิ่น เอม อร และไม่ซ้ำกับทีมมหาวิทยาลัย) |
| ชุดตัวละครเดิม ไม่สร้างสรรค์ | ออกแบบใหม่ ไม่ใช่ชุดนักศึกษา: ตังค์ฮู้ดดี้ส้มมัสตาร์ด ตาล้า หนวดเครา สายเป้; บีมฮู้ดดี้เขียวฟ้า หมวกแก๊ปแดง แก้มป่อง; พี่นุ่นชุดเขียวเข้ม มวยผมเสียบดินสอ ต่างหูห่วงทอง; โค้ชทองสูทเหลืองทอง แว่นดำ สร้อยทอง |
| "ไฟแดงครบชุด" | ใช้ "ธงแดง" ทั้งในเสียงเล่าและบนจอ (ธงแดง 3 ผืนเป็นมุกที่วนกลับตอนจบ) |
| เล่าไม่สนุก พูดแปลก | เขียนใหม่เป็นภาษาพูดของคนเล่าให้เพื่อนฟัง (ผู้เล่าเป็น "ผม" มีเพื่อนชื่อตังค์) เปิดด้วยประโยคเด็ดก่อน ใช้มุก "เงินแวะมาทักทาย" ตอนเปิดแล้วเรียกกลับตอนกลาง พี่นุ่นปากแห้ง บีมมั่นใจเกินเหตุ ตอนจบทิ้งมุกกวน (บีมไปสัมมนาโค้ชคนใหม่) ไม่สรุปบทเรียน |
| ให้ Gemini/GPT วิจารณ์ก่อนทำ | Gemini วิจารณ์ 2 รอบ (`critique.md`, `critique_round2.md`) แล้วแก้ตาม **GPT:** ผมเรียก GPT ไม่ได้ (ไม่มีคีย์ OpenAI) เตรียมพรอมต์ไว้ที่ `PROMPT_FOR_GPT.md` วางใน ChatGPT แล้วเอาคำวิจารณ์มาบอกผม ผมจะแก้ตาม |

## ที่ผมรับจากคำวิจารณ์ และที่ไม่รับ
- รับ: บีบเลขยิบย่อย, ตัดน้ำเสียงโฆษณาราชการของ ก.ล.ต., เลิกสรุปเป็นข้อแบบรายงาน (เปลี่ยนเป็นกฎบนทิชชูของพี่นุ่น), เอาคำตลกไว้ท้ายประโยค, callback "แวะมาทักทาย", ตอนจบกวน ๆ
- ไม่รับ: คำหยาบ (มึง/กู/ไอ้...) ที่ Gemini เสนอ เพราะไม่เหมาะกับช่องทั่วไป และเสี่ยงต่อการหารายได้
- คงไว้: คำเตือน "ไม่ใช่คำแนะนำการลงทุน" แต่ทำให้สั้นและเป็นมุก ("ขอพูดจริงจังสิบวินาที... จบสิบวินาที") เพราะเป็นเรื่องเงิน
