# FULL_EPISODE_PRODUCTION_PLAN — พับให้ถึงดวงจันทร์

บันทึกตามจริง: แผนนี้เขียนและปรับระหว่างการผลิต (ไม่ได้เขียนครบก่อนลงมือ) ตารางจริงหลังเรนเดอร์อยู่ใน `FINAL_PRODUCTION_REPORT.md`

## 1. แหล่งความจริงและสิ่งที่ตรวจก่อนผลิต
- บท: `STRESS_TEST_SCRIPTS_v2.md` เรื่องที่ 2 ทั้ง 7 ฉาก (0–6) ตามลำดับเดิม ไม่เปลี่ยนตอนจบ ไม่เพิ่มเหตุการณ์ใหม่
- รายงานที่อ่าน: `FEASIBILITY_REPORT.md`, `MATH_AND_GEOMETRY.md`, `SCENE_FEASIBILITY.md`, `visual_poc/`
- ระบบเดิมที่ใช้ซ้ำ: `prototype_v2` (หัว สีหน้า แขน IK มือ เงา), `shorts/sfx.py` (ดูแล้ว แต่ใช้เสียงที่สังเคราะห์ใหม่ใน `audio.py`), ตัวเรนเดอร์ภาษาไทยของ `shorts/subtitles.py` (พบว่าวรรณยุกต์หายจึงเขียนตัววาดข้อความเอง)
- เสียงที่มีอยู่แล้วในโครงการ: เสียงพากย์ที่แคชไว้เป็นของตอนอื่น (ไม่ตรงกับบทนี้) และ **ไม่พบไฟล์ดนตรีใด ๆ** → ไม่มีเสียงพากย์ ไม่มีดนตรีในตอนนี้ (ดู FINAL_PRODUCTION_REPORT)
- ทรัพยากรเครื่อง: 8 คอร์ (Intel i7-1195G7), RAM ≈ 15.7 GB, ดิสก์ว่างราว 147 GB

## 3. ส่วนประกอบที่ใช้ซ้ำ
`engine.py` (วงจรเดิน/วิ่ง คีย์เฟรม ท่า สีหน้า), `acting.py` (ท่าและสีหน้า), `props.py` (ฉาก ร้านชำ ลานวัด ครัว กระดาษ ชาม ลัง ฝูงชนแบบเงา), `captions.py` (ซับไตเติลภาษาไทยที่แก้วรรณยุกต์), `audio.py` (เสียงสังเคราะห์ 27 แบบ), `episode.py` (ตัวเรนเดอร์ 8 โปรเซส)

## 4. ความเสี่ยงและที่ตัดสินใจ
| เรื่อง | การตัดสินใจ |
|---|---|
| ไม่มีเสียงพากย์ที่ตรงกับบท และห้ามเรียก TTS/API | ใช้ซับไตเติลแทน และขยับปากตามช่วงเวลาที่ซับขึ้น (จังหวะ ไม่ใช่ลิปซิงก์) ไม่อ้างว่ามีเสียงพูด |
| ม้วนกว้าง 0.30 ม. (บท v2) vs 2 ม. (POC) | ผลิตด้วย **2 ม.** ดูเหตุผลและผลกระทบใน FINAL_PRODUCTION_REPORT |
| ตัวละครสี่ตัวไม่มีดีไซน์ที่อนุมัติ | ใช้ตัวแทนชั่วคราวที่สร้างบนโครงเดิม (`CHARACTER_DESIGNS/`) ไม่ถือเป็นดีไซน์อนุมัติ |
| โครงมีเสื้อผ้าสองแบบและขาไม่ขยับ | ห่อ (wrap) ฟังก์ชันขาในหน่วยความจำให้มีวงจรเดินวิ่ง; ไม่แก้ไฟล์ prototype_v2 |
| ภาพฝูงชน 100 คน | ใช้ตัวประกอบแบบเงาเรียบ (mini) ซึ่งมีสไตล์ต่างจากตัวละครหลักเล็กน้อย |
| ตัวเลข "สี่เท่า → สองร้อยเมตรกว่า เรามีร้อยเดียว" ในบทมีฐานอ้างอิงไม่ครบ (พบใน FEASIBILITY_REPORT) | **ไม่แก้บท** ใช้ตามบท และระบุเป็นความไม่สอดคล้องที่ยังเหลือ |
