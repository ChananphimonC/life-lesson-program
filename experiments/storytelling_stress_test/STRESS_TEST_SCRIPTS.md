# เรื่องที่ 1 — ผมจำได้ชัดมาก

## 1. ชื่อเรื่อง
**ผมจำได้ชัดมาก** (ประโยคนี้จะกลับมาอีกครั้งในฉากสุดท้าย ในความหมายที่ต่างออกไป)

## 2. แนวการเล่าและประสบการณ์ที่ต้องการให้คนดูรู้สึก
**Psychological Mystery / Thriller** คนดูต้องรู้สึกว่ากำลังสืบไปพร้อมกับดาบวิชัย: เห็นสิ่งที่ผิดปกติ ตั้งสมมติฐานเอง แล้วค่อย ๆ รู้ว่าความผิดปกติใหญ่กว่าที่คิด และแหล่งของมันอยู่ใกล้ตัวพระเอกมากกว่าที่เขาอยากรู้
ความรู้สึกที่ตั้งใจ: **สงสัย → ไม่สบายใจ → ขนลุก → โล่ง → เย็นวาบ** ไม่มีมุกตลก ไม่มีผู้บรรยาย ไม่มีใครอธิบายจิตวิทยา

## 2. แนวการเล่าและประสบการณ์ที่ต้องการให้คนดูรู้สึก
**Competition / Experiment / Comedy** เปลี่ยนจากการ "ยายพนันว่า 42" ในฉบับเก่า เป็น **เกมทายก่อนรู้คำตอบ** คำถามเดียวที่ทุกคนทาย: *"กระดาษแผ่นเดียว พับครึ่งกี่ครั้งถึงจะสูงถึงดวงจันทร์"* คนดูได้ทายด้วยในวินาทีที่ 25 ก่อนที่ใครจะรู้
ความรู้สึกที่ตั้งใจ: **ขำ → ตกใจกับตัวเลขที่เห็นด้วยตา → ลุ้น (ในการพับจริงของทั้งหมู่บ้าน) → "อ๋อ" ที่ตัวละครเดินไปถึงเองก่อนที่ใครจะบอก → ขำที่สุดตอนจบ**
ไม่มีผู้บรรยาย ไม่มีใครยืนอธิบายสูตร ความรู้ทั้งหมดมาจากสิ่งที่ตัวละครวัด พับ และคิดคำนวณเอง
