# Growth playbook (@SakidJai_สะกิดใจ)

ช่องที่ยังมีผู้ติดตามและยอดดูน้อยโตได้จาก 3 อย่าง: **คนคลิก** (ปก+ชื่อ) → **คนดูต่อ** (30 วินาทีแรก + จังหวะ) → **คนกลับมา** (ซีรีส์ + Shorts ชวนดูตอนเต็ม)
ไม่มีสูตรรับประกันยอด สิ่งที่ทำได้คือทำให้ทุกตอนผ่านเกณฑ์เดียวกัน แล้ววัดผลและปรับ

## 1. เส้นทางผู้ชม (Funnel)
1. **Shorts** (ตัดจากตอนจริงด้วย `python -m life_lesson.library short <id>`) → จบด้วยการ์ด "ดูเรื่องเต็มได้ที่ช่อง @SakidJai_สะกิดใจ"
2. **ตอนยาว/ตอนเดียวจบ** → คำอธิบายมีบทพร้อม timestamp + ลิงก์ช่อง
3. **Playlist/ซีรีส์** (`library playlist ...`) → ตอนจบหนึ่งตอนเปิดอีกตอน

ใช้ `--nth 2`, `--nth 3` เพื่อตัด Shorts คนละช่วงจากตอนเดียวกัน (ไม่ซ้ำกัน) และลองทั้ง `--layout fit` กับ `tall`

## 2. ก่อนกดเผยแพร่ (Quality gate — ต้องผ่านทุกข้อ)
- [ ] Critic ผ่าน (ไม่ใช่ `FAILED_REVIEW`) และคุณอ่าน/ฟังทั้งตอนแล้ว (`review_checklist.md`)
- [ ] 30 วินาทีแรกมี "ภาพ + คำถามค้าง" ไม่มีการทักทาย
- [ ] ปกอ่านออกที่ขนาดเล็ก (ตัวหนังสือ ≤ 6 พยางค์ต่อบรรทัด) ชื่อ ≤ 60 ตัวอักษร ไม่หลอกลวง
- [ ] เสียงพากย์ฟังแล้วไม่อ่านคำสั่งน้ำเสียงออกมา (ถ้าอ่าน ตั้ง `TTS_STYLE_DIRECTIVES=0`)
- [ ] เครดิต/ลิขสิทธิ์พื้นหลัง-ดนตรีครบ และติ๊ก "altered or synthetic content" ใน YouTube Studio
- [ ] Shorts: ตัวอักษรไม่ชนขอบล่าง/ขวา (UI ของ YouTube) ประโยคแรกเป็นภาพ

## 3. จังหวะการลง
- สม่ำเสมอดีกว่าถี่: เช่น 1 ตอนยาว/สัปดาห์ + 3–4 Shorts ที่ตัดจากตอนนั้น กระจายวัน
- ลงเวลาเดิมทุกครั้ง (ดูเวลาที่ผู้ชมออนไลน์ใน YouTube Studio → Audience)
- ใช้ Shorts ล่วงหน้า 1–2 วันก่อนตอนยาว เพื่อสร้างความอยากรู้

## 4. วงจรปรับปรุง (ทุกสัปดาห์ ~20 นาที)
ดูใน YouTube Studio แล้วจดลงตาราง:

| ตัวชี้วัด | ถ้าต่ำ แปลว่า | แก้ที่ |
|---|---|---|
| CTR ของปก | ปก/ชื่อไม่น่าคลิก | `library thumbnail <id> --title ... --tag ...` ลองหัวเรื่อง/แท็กใหม่ |
| ช่วงที่คนหลุด (Retention) ใน 30 วินาทีแรก | cold open ไม่ดึง | เปลี่ยนบทแรก/อารมณ์ (`mood`) ของ hook |
| ช่วงที่คนหลุดกลางเรื่อง | จังหวะช้า/เปลี่ยนฉากน้อย | เพิ่มจุดเปลี่ยนฉาก/ความตึง (tension) |
| Shorts → ผู้ติดตามใหม่ | ปิดท้ายไม่ชวนไปตอนเต็ม | ลองช่วง `--nth` อื่น / ใส่ลิงก์ตอนเต็ม `--full-url` |

แก้ปก/ชื่อของวิดีโอที่ลงไปแล้วได้ตลอด ไม่ต้องทำใหม่ทั้งตอน

## 5. สิ่งที่ระบบนี้ยังทำไม่ได้ (พูดตรงๆ)
- ไม่ได้อัปโหลด/ตั้งเวลาเผยแพร่ใน YouTube ให้ (ยังเป็นขั้นตอนมือ — อยู่ใน roadmap v1.0)
- ไม่ได้ดึงสถิติจาก YouTube Analytics ให้ ต้องดูเองและกรอกวงจรด้านบน
- ภาพเป็นสไตล์ flat ที่วาดด้วยโค้ด ไม่ใช่แอนิเมชันระดับสตูดิโอ ถ้าอยากยกระดับ ต้องต่อเครื่องมือสร้างภาพ (มักเสียเงิน)
