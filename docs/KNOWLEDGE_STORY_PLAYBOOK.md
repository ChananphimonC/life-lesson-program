## 1. ก่อนเขียน: เลือกมุมเล่า

ให้คะแนน 0–2 ต่อข้อ (ไม่ใช่การทำนายยอดวิว ใช้เพื่อเทียบมุมเล่าหลายแบบของหัวข้อเดียวกัน)

| เกณฑ์ | คำถามที่ต้องตอบได้ |
|---|---|
| อยากรู้ทันที | อ่านแค่ชื่อแล้วอยากรู้คำตอบไหม |
| เกี่ยวกับตัวคนดู | แตะปัญหา นิสัย ความเชื่อ หรือการตัดสินใจที่คนดูเจอจริงไหม |
| มีเรื่องให้เล่า | เล่าผ่านคน สถานการณ์ หรือการทดลองได้ไหม (ไม่ใช่แค่ข้อมูล) |
| มีจุดหักมุม | มีความเข้าใจผิด ผลลัพธ์ที่ไม่คาด หรือการเฉลยไหม |
| ภาพเล่าได้ | ฉากต่างกันอย่างมีความหมายได้ไหม ไม่ใช่ตัวละครยืนพูด |
| มีหลักฐาน | ข้อเท็จจริงสำคัญมีแหล่งที่ตรวจสอบได้ไหม |
| จบได้ใน 4–6 นาที | ตอบได้ครบโดยไม่ต้องยัด หรือไม่ต้องตัดสาระ |
| ไม่ซ้ำ | ต่างจากตอนที่มีแล้วในช่อง (MBTI, เงินเดือน, แพ้ท้อง) |

เขียนมุมเล่าอย่างน้อย 3 แบบแล้วเลือกแบบที่คะแนนรวมสูงสุดและมีเรื่องให้เล่าจริง

## 2. โครงเรื่อง 6 ช่วง (ยืดหยุ่น ไม่ใช่สูตรตายตัว)

1. **เปิดในสถานการณ์ (3–15 วิ):** เริ่มกลางเหตุการณ์ที่คุ้นเคย มีความขัดแย้งเล็ก ๆ และทิ้งคำถามที่อยากรู้ ห้ามเปิดด้วยการทักทาย นิยามศัพท์ หรือคำอุทานที่ไม่มีเหตุการณ์รองรับ
2. **ทำให้เป็นเรื่องของคน:** ตัวละครอยากอะไร เชื่ออะไร เสี่ยงอะไร ใช้รายละเอียดจับต้องได้ (เวลา ราคา ของในมือ)
3. **ยกระดับคำถาม:** แต่ละฉากเพิ่มผลที่ตามมา ข้อมูลที่ขัดกับความเชื่อเดิม หรือคำถามถัดไป อย่าเฉลยทั้งหมดตั้งแต่ต้น
4. **หลักฐาน/การค้นพบ:** ใส่ข้อมูลจริงเมื่อมันช่วยเรื่อง แปลตัวเลขเป็นภาษาคน ("แปลว่า…") ใช้การทดลองหรือการเปรียบเทียบเป็นฉาก
5. **เฉลย:** คำตอบที่ได้มาจากหลักฐานในเรื่อง ห้ามแต่งการหักมุมให้เกินหลักฐาน
6. **จบให้จำได้:** ข้อคิดสั้น ผลที่น่าสนใจ หรือคำถามต่อยอด ชวนติดตามได้สั้น ๆ ไม่แทรกกลางเรื่อง

ทุกช่วงต้องเขียน "ผู้ชมได้อะไรใหม่" 1 บรรทัดในโครงเรื่อง (คำถามใหม่ / ข้อมูลใหม่ / การกระทำ / การเฉลย) ถ้าช่วงไหนเขียนไม่ได้ ให้ตัดหรือรวม

## 3. ภาษาพูดไทย

- เขียนให้ "คนเล่าให้เพื่อนฟัง" ฟังแล้วเข้าใจโดยไม่ต้องอ่านซับ ประโยคสั้นยาวสลับกัน
- เลี่ยงภาษาเอกสาร คำแปล คำเชื่อมแบบรายงาน ("ข้อแรก" "ข้อที่สอง" "สรุปก็คือ" "ทั้งนี้") ถ้าต้องไล่หลายข้อ ให้เปลี่ยนเป็นเหตุการณ์หรือการเปรียบเทียบ
- คำถามใช้เมื่อมีเหตุผล ไม่ใช่ท้ายทุกย่อหน้า มุกตลกมาจากสถานการณ์และจังหวะ ไม่ใช่คำอุทาน
- คำเตือนหรือข้อจำกัดของข้อมูล ใส่ครั้งเดียวในจุดที่เกี่ยว ไม่ซ้ำทุกช่วง
- ตัวเลขใน `say` เขียนเป็นคำอ่าน ชื่อเฉพาะสะกดตามเสียง เลี่ยงคำที่ TTS เคยพลาด (ดูเช็กลิสต์)
- เรื่องสมมติต้องบอกว่าสมมติเมื่ออาจถูกเข้าใจว่าเป็นเรื่องจริง ห้ามแต่งประสบการณ์ส่วนตัวแล้วอ้างว่าจริง

## 4. Storyboard (ต้องมีก่อนพากย์และก่อนเรนเดอร์)

แต่ละช็อตต้องระบุ: จุดประสงค์ในเรื่อง · สิ่งที่เกิดขึ้นจริงในภาพ · ท่าทาง/สีหน้า/สายตา/ของในมือ · ขนาดภาพและมุม · องค์ประกอบและฉากหลัง · การเคลื่อนไหว (ถ้ามีเหตุผล) · ช่วงเสียงที่ตรงกัน · ข้อความบนจอและเหตุผลที่ต้องมี

แนวทาง: เปลี่ยนภาพอย่างมีความหมายทุก ~5–10 วินาที (ไม่ใช่กฎตายตัว) ตัดภาพบนช่วงหยุดของเสียง ไม่ตัดกลางคำหรือกลางมุก

## 5. เช็กลิสต์ตรวจบท (ก่อนใช้โควตา TTS)

**เรื่องและจังหวะ**
- [ ] 15 วินาทีแรกมีสถานการณ์ + ความขัดแย้ง + คำถาม
- [ ] ทุกช่วงมี "ผู้ชมได้อะไรใหม่" ไม่มีย่อหน้าที่พูดซ้ำความหมายเดิม
- [ ] ไม่มีคำเชื่อมแบบรายการ/รายงาน และไม่มีคำอุทานที่ไม่มีเหตุการณ์รองรับ
- [ ] คำเตือนอยู่ครั้งเดียวในจุดที่เกี่ยว
- [ ] ความยาวโดยประมาณ (≈12 ตัวอักษรไทยต่อวินาที) พอดีกับเรื่อง ไม่ยัดให้ถึงเป้า

**ข้อเท็จจริง**
- [ ] ข้อเท็จจริงทุกข้อมีแหล่งใน `sources[]` พร้อม "ข้อความที่แหล่งนี้รองรับ"
- [ ] แยก: ผลวัดจริง / ค่าประมาณ / สมมติฐานของเรื่อง / ความเชื่อ / เรื่องแต่ง
- [ ] หลักฐานจำกัดหรือกลุ่มตัวอย่างเล็ก บอกตรง ๆ; ไม่ทำความสัมพันธ์ให้เป็นเหตุผล; ไม่เหมาผลต่างประเทศว่าใช้กับไทยแน่นอน
- [ ] ตัวเลขคำนวณตรวจซ้ำแล้ว และเก็บสูตรใน `note`
- [ ] สุขภาพ: มีบริบทความปลอดภัย ไม่อ้างเกินหลักฐาน; ความเชื่อ: เล่าอย่างให้เกียรติ ไม่ล้อคนเชื่อ

**เสียงและตัวอักษร (บทเรียนจากตอนที่ผ่านมา)**
- [ ] คำแรกของแต่ละช่วงเสียงเป็นคำง่าย (Gemini มักเพี้ยนคำแรก: "แฟ้ม"→"แถม", "เบาะแส"→"บอกแส", "แต่"→"ไต่")
- [ ] เลี่ยงคำที่เคยเพี้ยน: ราว (→เรา), ฝั่ง/ฟัง, ทาย, สุก ๆ ดิบ ๆ (→สุข), ค่าห้อง (→ถ้าห้อง)
- [ ] ข้อความบนจอเลี่ยงวรรณยุกต์ซ้อนสระบน (ที่ นี้ นั่ง เสี่ยง น้ำ เนื้อ ดื่ม) และลูกศร → จนกว่าจะแก้ฟอนต์
