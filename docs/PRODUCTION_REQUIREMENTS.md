# Requirement การผลิตตอน (ตัวละคร · เสียง · ฉาก · แสง · แอนิเมชัน · Shorts · ซับ)

สถานะ: ✅ ทำแล้ว · 🟡 ทำบางส่วน · ⬜ ยังไม่ทำ (ซื่อสัตย์ตามที่ตรวจในโค้ดวันนี้)

## 1. ตัวละคร
- ตัวหลักเด่นกว่า (ใหญ่ 1.1×, แสงนวล) และคนที่จะพูดต่อได้โคลสอัพของตัวเองเมื่อถึงบล็อกที่มี `speaker` ✅
- ผู้หญิง: เอวคอด ผมยาว/เป็นลอน ขนตา แก้ม; ชุดเดียวตลอดเรื่องตาม character sheet ✅
- ทุกเรื่องต้องมี `characters` (ชื่อ บทบาท ชุด ผม เพศ) และ `speaker` ทุกบล็อกที่มีบทพูด ✅
- 🟡 ตัวประกอบยังใช้โครงเดียวกัน (ต่างกันแค่สี) · ⬜ ไม่มีโคลสอัพจริง (ซูมภาพเท่านั้น)

## 2. เสียงพากย์
- Gemini TTS เสียง Kore รายบล็อก แคชบนดิสก์ มาสเตอร์ −16 LUFS ✅
- คำสั่งน้ำเสียงตาม `mood.voice` · ต้องฟังตัวอย่าง 1–2 บล็อกก่อนผลิตจริง ✅ (ฝั่ง agent ที่มีคีย์)
- ⬜ แยกเสียงตัวละคร (ตอนนี้ผู้เล่าคนเดียวอ่านบทพูดด้วย)

## 3. ฉาก แสง เสียงบรรยากาศ
- 11 ฉากวาดจากโค้ด ฟรี สไตล์แบน; แสง/สี/ฝน/หมอก/เสียงบรรยากาศตาม `mood` ✅
- ฉากเปลี่ยนตามช่วงเรื่อง (เปลี่ยนเมื่อชื่อบท/สถานที่เปลี่ยน) ✅
- ⬜ ฉากที่เรื่อง "ข้าวมันไก่" ต้องการ: ตลาดสด · รถไฟฟ้า BTS · ห้างสรรพสินค้า · รถสามล้อพ่วงมอเตอร์ไซค์ พร้อมไก่แขวน — ตอนนี้ใช้ฉากใกล้เคียง (street/bus/city) ไปก่อน

## 4. แอนิเมชัน (ต้องขยับ ขยับตรงคำพูด)
- ✅ หายใจ กะพริบตา · ปากคนพูดเปิด/ครึ่ง/ปิดสลับ · เจ๊ผัดกระเพราเหวี่ยงตะหลิว · เดิน (ขา แขน ตัวเด้ง)
- 🟡 ปากขยับ "ระหว่างบล็อกที่คนนั้นพูด" แต่ยังไม่ซิงก์กับพยางค์/เสียงจริง (ยังไม่วิเคราะห์คลื่นเสียง)
- ⬜ ท่าจับของ (สับไก่ ตักข้าว ยื่นจาน นับเหรียญ ถือกาแฟ) · เดินข้ามจอ (ตอนนี้เดินอยู่กับที่)
- ภาพแบบ "สมจริง" ทั้งหมด: **ทำไม่ได้ด้วยตัววาดโค้ดนี้** และไม่ฟรี — ที่ทำได้คือ flat คุณภาพสูง (แสง เงา ไอน้ำ ของประกอบละเอียด) ตามลุคที่เจ้าของอนุมัติแล้ว ถ้าต้องการสมจริงจริงต้องใช้ตัวสร้างภาพ/วิดีโอแบบเสียเงิน ให้เจ้าของตัดสิน

## 5. คลิปยาว vs Shorts
- Shorts 30–55 วินาที ตัดจากตอนจริง ไม่สปอยล์ตอนจบ **ต้องดูแล้วเข้าใจทั้งเรื่อง**: เปิดสถานการณ์ → ปมกลาง → ปิดด้วยคำถาม + CTA ไปดูตอนเต็ม ✅ (เลย์เอาต์ล็อกแล้ว)
- คลิปยาวใช้เรื่องเดียวกัน แต่เพิ่มรายละเอียด (ขั้นตอนทำ ตัวเลข ความรู้สึก) และ **ต้องจบเหมือนกัน** · เกณฑ์: เนื้อหาต่อนาทีมากกว่า Shorts ไม่ใช่แค่ยืดเวลา ✅ (กำหนดไว้ในสเปก)
- ปุ่มกดติดตาม: Shorts มีการ์ดปิดท้าย ✅ · ⬜ คลิปยาวยังไม่มี end card/คำชวนติดตามกลางเรื่อง

## 6. คำบรรยาย (ซับ) — วรรณยุกต์ห้ามตก
- Shorts มีคำบรรยายไทยในแถบล่าง ✅
- ⬜ คลิปยาวยังไม่ฝังซับ (ROADMAP v0.4) และยังไม่มีไฟล์ .srt
- เกณฑ์รับ: ใช้ฟอนต์ไทยที่มีสระ/วรรณยุกต์ครบ (Noto Sans Thai/Sarabun) · ตรวจว่าสระลอย/วรรณยุกต์ไม่ซ้อน-หาย โดยเปิดดูเฟรมจริง · ข้อความซับ = ข้อความบทเป๊ะ (ไม่ถอดเสียงใหม่) · แบ่งบรรทัดไม่ตัดกลางคำ

## 7. ลำดับงานที่เสนอ (ทำทีละก้อน commit เล็ก)
1. ฉาก/ของประกอบข้าวมันไก่ (ตลาด รถสามล้อ BTS ห้าง ไก่แขวน) ← ถัดไป
2. ท่าจับของ + เดินข้ามจอ + ปากซิงก์จากเสียง
3. ซับฝังคลิปยาว + .srt + end card ติดตาม
4. (ถ้าเจ้าของต้องการ) ทางเลือกภาพสมจริงแบบเสียเงิน
