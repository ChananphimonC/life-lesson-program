# Script doctor — ทำให้บทน่าติดตาม

ขั้นตอนอัตโนมัติหลังสร้างบท ก่อน Critic (`--no-punchup` ปิดได้):

```
สร้างบท (prompt v0.5 + SUSPENSE ENGINE)
  → ตัวตรวจ (suspense.py)      หาข้อบกพร่องเป็นข้อๆ พร้อมเลขบล็อก
  → ถ้าคะแนน < PUNCHUP_THRESHOLD (75)  ให้โมเดลเขียนใหม่ตามข้อบกพร่อง (สูงสุด 2 รอบ)
  → ผู้อ่านจำลอง (LLM เทียบ A/B สลับลำดับ 2 ครั้ง)  ฉบับใหม่ต้องชนะทั้งสองครั้ง
  → Critic (ตามซีรีส์) → เสียง → ภาพ
```

## ตัวตรวจแยกเป็น 2 ชนิด (สำคัญ)
| ชนิด | ตัวอย่าง | น้ำหนัก | ตัดสินว่าฉบับใหม่ดีกว่าไหม |
|---|---|---|---|
| **เชิงกลไก** ตรวจได้แน่ | เปิดด้วยการทักทาย · ศัพท์รายงาน (ข้อแรก/สรุปก็คือ/ทั้งนี้) · บรรยายสีหน้า-ท่าทาง-เสื้อผ้า · ตัวเลขเป็นตัวเลข · วลีซ้ำ · โค้งความตึงแบน/ตก · ไม่มีแหล่งอ้างอิง (knowledge) · จบแบบสรุปบทเรียน (reflection) | เต็ม | ใช่: ฉบับใหม่ต้อง **ไม่มีปัญหาเชิงกลไกเพิ่ม** |
| **เชิงความรู้สึก** (ประมาณการ) | ฮุกไม่ชัด · ตอนจบบทไม่ทิ้งคำถาม · คำถามค้างน้อย · จังหวะเรียบ | ครึ่งน้ำหนัก | ไม่: เป็นแค่คำใบ้ให้ผู้เขียนใหม่ — ตรวจด้วยคำสำคัญจึงวัดความระทึกจริงไม่ได้ |

> ตัวอย่างจริง: ฉากเปิดเกาะ 72 ชั่วโมงฉบับเดิม ปัญหาเชิงกลไก 6 (บรรยายสิ่งที่ภาพโชว์) / ฉบับปรับใหม่ 0 แต่คะแนนรวมใกล้กัน (90 vs 88)
> เพราะคะแนนไม่ได้บอกว่า "ฉบับไหนสนุกกว่า" — ให้ผู้อ่านจำลองและมนุษย์ตัดสินส่วนนั้น (`stories/island_72/OPENING_IMPROVED.md` เทียบกับ SCRIPT.md เดิม)

## ซีรีส์
`--series reflection` (Life Lesson: ไม่แนะนำ จบเปิด) · `knowledge` (รู้หรือไม่: ข้อมูลต้องมีแหล่ง แยกความเชื่อ/หลักฐาน ให้คำแนะนำได้)
· `story` (เรื่องแต่งสนุก ๆ: ห้ามเหยียดบุคคลจริง/ลอก IP/เรื่องรุนแรง) — แต่ละสายมี prompt และหมวด Critic ของตัวเอง

## ใบสั่งงาน (`--brief`)
`stories/*/BRIEF.md` เก็บเฉพาะ **สิ่งที่ควรคงไว้** จากงานเดิม (ตัวละคร+สีประจำตัว, ข้อเท็จจริง+แหล่ง, ลำดับเหตุการณ์, ข้อควรระวัง) ไม่ลากร้อยแก้วเดิมมา:

```bash
python -m life_lesson.cli "ถ้ามหาวิทยาลัยดัง ๆ ติดเกาะร้าง 72 ชั่วโมง" --series story --format long --brief stories/island_72/BRIEF.md
python -m life_lesson.cli "ทำไมคนท้องอยากกินของแปลก" --series knowledge --brief stories/know_craving/BRIEF.md
python -m life_lesson.cli "เงินล้านใน 2 ปี ทำได้จริงไหม" --series knowledge --brief stories/money_v2/BRIEF.md
```
