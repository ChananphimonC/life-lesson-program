# Background videos

Drop pre-curated, looping, 16:9 stock background videos here (`.mp4`, `.mov`,
`.mkv`, or `.webm`). The v0.1 pipeline picks one at random for each episode
(REQUIREMENTS.md: "Pre-curated folder of stock looping videos, no AI video
generation").

This folder is empty by default -- the pipeline will raise a clear error if
no video files are present when it tries to assemble an episode.
